# 번역 파일

`ko.json`이 원본입니다. `en.json`과 `ja.json`은 같은 키 구조에 값만 비어 있고,
**비어 있는 값은 한국어로 자동 대체**됩니다 (`src/i18n/request.ts`).

그래서 한 번에 다 채울 필요가 없습니다. 값을 하나 채우면 그 자리만 해당 언어로
바뀌고, 나머지는 한국어로 남습니다. 반쯤 번역된 파일이 페이지를 깨뜨리지 않습니다.

```jsonc
// en.json
"sections": {
  "experience": "Selected Work",   // ← 채운 것: 영어로 보임
  "skills": ""                     // ← 빈 것:   "쓰는 도구들" 로 보임
}
```

## 키 추가할 때

세 파일 모두에 같은 키를 넣어 주세요. `ko.json`에만 있으면 en/ja는 폴백으로
동작하지만, 빈 슬롯이 목록에 보이지 않아 채울 것을 놓치기 쉽습니다.

`{title}` 같은 중괄호는 코드에서 넘기는 값이라 번역문에도 그대로 남겨야 합니다.

## 지금 번역 대상이 아닌 것

`src/pagesLayer/home/data.ts` 의 내용(프로필·프로젝트·경력·스킬)은 한국어
그대로입니다. 이 파일은 `pnpm data:real` 로 저장소 밖의 실제 이력서 파일을
덮어쓰는 구조라, 다국어로 만들려면 그 파일도 같은 모양으로 바꿔야 합니다.

## 언어 추가

`src/i18n/routing.ts` 의 `locales`, `localeNames`, `htmlLang` 에 추가하고
`messages/<코드>.json` 을 만들면 됩니다. 라우팅·스위처·정적 생성은 그 목록을
따라가므로 다른 곳은 건드릴 필요가 없습니다.
